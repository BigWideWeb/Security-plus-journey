# Module: Operating Systems Basics — TryHackMe Pre Security

Covered what an OS actually does, plus hands-on basics in both Windows and Linux command lines, and OS-level security.

## What I learned

- **What an OS does:** it's the intermediary between hardware and software. From managing memory, processes, and even files so applications don't have to talk to hardware directly. See an OS as a middleman.
- **Windows basics:** still the dominant OS in most enterprise/business environments.
- **Linux CLI basics:** this is the one that matters most for where I'm headed. Most servers and a lot of security tooling run on Linux, so command-line comfort here isn't optional for SOC work.
- **Windows CLI basics:** Command Prompt and PowerShell, the Windows equivalent of Linux terminal work.
- **OS security:** user accounts, permissions, and patching. This is where most breaches exploit gaps here (unpatched systems, excessive permissions) rather than some exotic attack.

## What confused me

I Initially treated the Windows CLI and Linux CLI as basically the same thing with different commands; realized they're different enough (syntax, philosophy, how permissions work) that I need to practice both deliberately rather than assuming one transfers cleanly to the other.
