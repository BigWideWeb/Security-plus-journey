# Module: Software Basics — TryHackMe Pre Security

Covered how computers represent and encode data, a first look at Python and JavaScript, and SQL basics.

## What I learned

- **Data representation:** computers store everything as binary (0s and 1s). Whether it's text, images,anthing at all; everything eventually breaks down to this.
- **Data encoding:** how raw binary gets translated into meaningful data types (text encoding like UTF-8, etc.). Honestly, for me, this is closer to security than I expected, since encoding issues show up in things like injection attacks.
- **Python & JavaScript (simple demos):** first real look at each language in this context.
- **Database SQL basics:** querying and structuring data. This is relevant since SOC work involves querying logs and security data constantly.
