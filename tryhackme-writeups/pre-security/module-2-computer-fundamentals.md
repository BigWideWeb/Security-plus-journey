# Module: Computer Fundamentals — TryHackMe Pre Security

Covered the physical/conceptual building blocks of computers, the client-server model, and an intro to virtualization and cloud.

## What I learned

- **Inside a computer:** the CPU processes instructions (the "brain"), RAM is fast temporary memory that clears when power's off, and storage (HDD/SSD) holds data permanently. The motherboard ties it all together, "She" is the backbone.
- **Computer types:** desktops, laptops, servers, and mobile devices aren't just "different sizes"; they're built for different jobs. Servers in particular are built for uptime and handling many requests at once, not user comfort.
- **Client-server basics:** the client requests, the server responds. This is the foundational model behind almost everything networked; web browsing, apps, even most security tools.
- **Virtualization:** running multiple isolated "virtual" computers on one physical machine. This clicked as directly relevant to security. It's how safe lab environments (like a home lab) and sandboxing work. I have used virtual machines in the past but I can say that, I didn't know about Hypervisors until now; and that there are 2 types. 
- **Cloud computing fundamentals:** renting computing resources instead of owning physical hardware, via models like IaaS/PaaS/SaaS.

## What confused me

Virtualization vs. cloud computing felt like the same thing at first. I now see virtualization is the *foundation technology*, and cloud computing is a *business model* built on top of it (a cloud provider runs lots of virtual machines for customers).
